### Worktree hygiene

Each wave worktree's `assets/` is a symlink farm and `outputs/` symlinks to
main's. Two consequences: **never `git add -A` in a worktree** (it commits a
spurious `D assets/weights/.gitkeep`), and **two streams writing the same
`outputs/` subdirectory will clobber each other** — use the per-brief output
path and no other.
