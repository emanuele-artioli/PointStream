### Worktree hygiene

Each worktree's `assets/` is a symlink farm and `outputs/` symlinks to main's.
**Never `git add -A` in a worktree** — it commits a spurious
`D assets/weights/.gitkeep`. Two streams writing the same `outputs/` subdirectory
will clobber each other: use only your brief's output path.

### Lessons from wave 4 worth not repeating

- **A long job goes in the harness's own background mechanism**, not `setsid` /
  `nohup` — a shell-detached run still died to the tool timeout.
- **`conda run` swallows pytest's summary line on this host.** Use
  `--junit-xml` to read counts; a piped exit code is not evidence.
- **Confirm CI green before saying it is.** `4acaabe` was pushed with a red lint
  and merged that way; main was red until `#21`.
- **Verify a process is dead with `ps` before relaunching it.** A notification is
  not proof, and a relaunch that starts with `rm -rf` destroys the evidence.
