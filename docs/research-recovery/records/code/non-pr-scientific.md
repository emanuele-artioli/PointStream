# Significant scientific code outside simple PR ancestry

PR branch ancestry does not cover the entire project. Squash-merge commits can carry `(#N)` while their hash is not an ancestor of the recovered PR head, and direct development commits also carry crucial repairs. This record inspects retained diffs, not titles alone. Full patch captures are under `workers/code/nonpr/`; code changes below establish implementation and historical correction, not a newly replicated measurement.

## August 20–22: contracts and reconstruction become explicit

`38b23f87a8068f509267c47aaca69ee5fe116b9a` adds typed conditioning and metric contracts. `src/contracts/conditioning.py` replaces an overloaded dense-pose slot with named fields and derives the conditioning plan from declared generator requirements. `src/contracts/metrics.py` requires PSNR, rejects empty metric selections and records direction/tier information. This matters because code previously inferred needs from backend names or class identity; explicit contracts expose incompatible combinations. It is not proof that the requested information reaches a qualified checkpoint.

`0bbc256b0041def3524bb2a6092fd98a5bc843a5` adds object-stream, domain and ablation-lattice contracts. Appearance/motion/temporal policy have separate choices; generator compatibility, sparse-point limits, cut handling and enabled-stage dependencies are validated. The camera-motion profile rejects panorama use under unrestricted camera motion. These are implementation safeguards against silent nonsensical configurations. A stated cost or validation rule is not actual emitted-wire accounting.

`26533b082eca39fafb693db07abb3b572c53413b` introduces the lattice-driven encoder DAG and clock-based tests that disabled stages do not execute. `ee22715c37133fc6c83fdfe6e618cdf2afa6ee7b` splits background warp, clips, compositing, device policy, dispatch and reconstruction quality into independent modules. Its all-off path returns the source bit-for-bit, which is a useful baseline/invariant but cannot stand for compression unless a transported conventional spine is separately established. Later audits distinguish a special source-return branch from a fully costed codec. Routine type/test changes around this rewrite must not be counted as new experimental samples.

## August 22–24: conditioning and measurements are repaired

`0603189b5fc28f1de4b703ba694d0e0e39fe5426` corrects the IP-Adapter path: tests capture distinct appearance as `ip_adapter_image` and pose as the control image, and weight selection stops resolving a mislabelled fine-tune. The old name did not establish an appearance pathway. This is a real capability repair; inherited results from the mislabelled checkpoint remain invalid for IP-Adapter claims.

`7972608b8c029f520d3d0e1bf9bc15329769a062` changes training and inference for pose-reference ControlNet. It samples a different same-track reference, skips one-frame tracks, paints skeleton over appearance consistently, and offers a smoke check that zeroing the reference changes ControlNet residuals. These checks prove a conditioning path can carry reference information. They do not prove output identity fidelity, improved coding-task quality or generalization; reference selection and training exposure remain part of the protocol.

`8bdd2cea59ba68f94bf8049102bef6f35bb27cf0` changes probe interpretation from self-reconstruction to a coding task with different target/reference frames and a same-offset static-copy floor. `9cea0df52ab5084e35c66199fbe0bac68907f76e` subsequently retires cross-appearance ranking as a quality test. Its new verdicts say reference-dependent, weakly dependent or independent and normalize against a pure-copy control: a paste can top the dependence statistic without generative reconstruction. This correction separates three questions previously conflated: whether reference information enters the model, whether the output changes when reference changes, and whether it reconstructs the right moving object accurately.

`4721e65b4df5db640fc0e47c3f1a5d6c20f8d494` replaces the `src/components/metrics/lpips.py` backend's uncalibrated VGG feature MSE with `lpips_pkg.LPIPS(net=net, verbose=False)` and actual normalized frame batches. Tests add known-anchor/range checks rather than only positive distance for different images. The accompanying historical notes explicitly void prior LPIPS rankings. This is a comparability boundary: no pre-repair figure should be combined with calibrated LPIPS or cited as the published metric. The code inspection confirms replacement; anchor values and new model scores are reported historical observations, not rerun here.

`60d9b262dbf9874a0355103e250c3c83d5a5e7fe` repairs `src/components/metrics/vmaf.py` to feed distorted/reference in libvmaf's required order, with textured-content tests and rejection of too-small crops. It adds package dependencies and DISTS-related integration coverage. VMAF role reversal means early scores cannot establish favorable perceptual ranking. `32455f78363d7f906ff5ab0ee8824b59488a9366` adds calibration invariants using structured anchors and ordering/range constraints; it explicitly avoids assuming severe blur must always be closer than unrelated images. This is measurement qualification work, separate from codec performance.

`b187f74e1112e8615a2d3821c84b67a424ecf762` introduces full-body reidentification/palette instruments to assess identity rather than faces or generic distortion. `6f36d75207390e5ca8d30fda1ba3d66ba2d7f7a2` replaces a hand-labelled decisive scale with simultaneous overlapping track pairs and introduces `IdentityScale`, preserving below-stranger outcomes rather than clamping them. The historical seven-video separation estimates are tied to this dataset/backbone and tracking assumptions. A same-track identity assumption can still fail under ID switches; this is an explicit metric/annotation protocol, not ground-truth identity everywhere or evidence of codec success.

`f707d09006da2dbf41f00223767dd7887d19bf06` propagates per-track caption through sample/clip payloads and `ConditioningBundle`, loads the training sidecar with fallback, and records whether generation actually used the caption. The inference prompt changes from generic text to the text conditioning used in training. This corrects another train/inference mismatch; the captured-pipeline tests establish prompt delivery, not improved generated quality.

## Conventional diagnostic and retiring the old implementation

`25fa1ac614e1ea93f559aa7cec270eafec799139` adds the conventional headroom diagnostic; `be9c02216fcd8949c70a91b7f2d48e0e98587afb` moves to real 4K ladder inputs and relevant mask/region accounting. These commits matter because they replace synthetic/single-point narrative with changed-target conventional encoding experiments. The promoted “player bits” interpretation still needs the scope preserved: removal and panorama targets change signal statistics, so any savings are a diagnostic opportunity, not an isolated causal bitrate attribution or transported player replacement.

`84702119fd571875bbc3d43ed678d77908dd683c` records the AVC addroi/QP no-op finding. It is a documented negative implementation result under the tested build/settings; parser acceptance alone cannot prove ROI active. `14d7ef24fb71a66555300d154ab52dfe6de2691e` removes the pre-rewrite encoder and its legacy tests while retaining FFmpeg I/O used by the decoder. This is a large retirement change, not loss of an accepted codec result or empirical proof of the replacement. Removed tests cannot certify old behavior retroactively, and fewer tests do not mean less experimental evidence.
