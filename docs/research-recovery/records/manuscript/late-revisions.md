### Background plate and stream claims

- **Sidecar still-image codec (Aug. 29, ad4b342c5c9a0748af9f3ca87b736eea6ae72fc8).** The recorded one-plate probe at about 38 dB is JPEG 283,431 B, AV1-intra 79,726 B, and VVC-intra 68,477 B: a 3.6–4.1× difference in one component. The commit explicitly marks the codec axis NEXT/unswept; no end-to-end ladder used those alternatives. Manuscript pointers: outputs/bp24-ladder/plate-probe.json and plans/BP29-plate-rate.md. The later two-window measurement described in the dirty patch uses WebP stills for plate, crops, and per-frame residual; that is an implementation choice, not a matched still-codec sweep.
- **Early “panorama delta” note (Aug. 29, 856b34c16a7de704dff5cd64592f839caee43cea).** The commit text reports AV1 inter-frame coding of a later plate at 31–53% fewer bytes than a fresh plate between match points, versus a 1.2–3.3% adjacent-frame control within a point. The later correction says the code path called panorama delta was pixel subtraction, not inter coding. Do not attribute the AV1 result to pixel subtraction.
- **Corrected cross-scene background stream (Aug. 31, 802088d363ff98e0e3bebeb6f43da546b8cde6ba).** The actual stream test codes each new scene background plate against the prior scene’s decoded reconstruction using libaom AV1 low-delay P coding, 4K, CRF 38, over five videos × 16 scenes. Fresh-plate byte-cost ratio averages 49.2% ± 6.2%, with a 29.4% best and 62.4% worst per-video result; the within-scene adjacent-frame control is 0.0074. Code pointers: experiments/tier/background_stream.py, src/components/background/stream.py, tests/components/test_background_stream.py. Run records: outputs/bp30-background/stream-sweep-<video>.json. This supports a bounded component byte-count result and tested packet prefix-stability/equal-decoded-reference properties. It does not establish a whole-codec rate–distortion advantage: the manuscript itself says the paired ladder was not rerun with the stream. A fair rerun must give the anchor the same N scenes, low-delay settings, and keyframe interval. Canonical canvas preparation remains offline, so packet causality is not end-to-end causal acquisition. The correction says pixel-subtraction delta costs 1.49–1.70× the fresh-plate bytes at about 13 dB lower quality; stream savings are AV1-specific (x265 saves 12% on one pair, loses 6% on another). Reference-selection changes were not worthwhile on the five-video records.
- **Do not collapse a component saving into quality or system victory.** The earlier 8-frame paired ladder at base commit 6f86e3 records PointStream BD-rate disadvantages of +116.8% vs AV1, +166.8% vs HEVC, +165.9% vs AVC, and +378.1% vs VVC over only the shared 39.45–44.02 dB range on the most static cached clip. There is no overlap on the most dynamic clip (PointStream tops at 31.0 dB vs AV1 cheapest rung 38.03 dB). Plate share is 88–91% and residual share 3–9%. These are bounded historical measurements, not universal evidence against later configurations.

## Suggested paper-use paragraphs

**Background stream.** “For compatible camera contexts, PointStream can code a later background plate as a low-delay AV1 inter frame against the preceding decoded plate. In a five-video, 16-scene-per-video sweep, this stream used 49.2% ± 6.2% of the bytes required to code each plate afresh (per-video range 29.4–62.4%). This is a background-component byte count; it does not establish a whole-codec rate–distortion gain. Canvas preparation remains offline, and a fair end-to-end comparison must provide both codecs the same decoded history and scene sequence.” Keep provenance in a nearby marker; do not present the still-codec probe or pixel delta as this result.

**Comparison protocol.** “All compressed comparisons use an explicit coded reference on identical source frames; raw all-off pixel passthrough is a diagnostic, not a rate point. We charge background initialization and updates, object references and motion, residuals, container data, and any fitted state, and score an independently decoded output. Development, model selection and confirmation are separated at match level; reserved footage receives only score-free eligibility checks until the protocol is frozen. Gate A/B and BP51–57 pilots are development/instrumentation records, not confirmation.”

**Results.** “The Sept. 21 modular rate-reduction, six-match and second-domain statements are withdrawn: their cited values were table outputs rather than encodes. In the later two-window WebP-still records, C1 is larger than VVC on both tested windows; the 48-frame example is 528,958 B vs 112,295 B with 35.6 dB foreground but 20.5 dB overall PSNR, while the 192-frame example is 2,883,316 B vs 258,024 B. These observations do not establish a winning regime; Pose OKS was not measured, and no second domain was encoded.” Before integrating those exact point values, retain their source identity and raw-artifact status from the dirty patch and campaign record; the September audit did not independently reproduce them.
