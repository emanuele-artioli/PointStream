# How this dossier treats evidence

This is a retrospective audit collected from 30 September 2026. It does not run new GPU experiments, integrate the manuscript, or certify missing comparisons. The audit leaves source trees and original artifacts untouched; live user work is pinned and rechecked separately. Derived CPU analyses are identified separately from historical observations.

## Evidence status

- **Validated positive / negative within tested conditions:** the saved artifact, code path and available provenance support the bounded observation. Validation is never a universal result or an independent reproduction unless explicitly stated.
- **Diagnostic / oracle:** altered targets, privileged side information, capacity probes, synthetic clips, or single operating points supporting a narrower question.
- **Implementation failure:** the intended algorithm or instrument did not execute correctly; this cannot establish algorithmic inferiority.
- **Invalidated / retracted:** later audits or contradictions void the original interpretation; retain the observation and correction chain.
- **Unresolved:** essential identity, accounting, calibration, or comparison evidence is absent.

A successful process, code presence, available checkpoint, or favorable filename does not establish a paper result. Prior summaries and session conclusions are discovery leads. Raw observations, implementation paths and later corrections determine interpretation. No negative result closes an entire model family.

## Comparison eligibility

Keep source/frame/window identity, split role, target, quality axis and implementation, receiver information access, full-wire accounting, preprocessing and deployment costs, model/checkpoint, and timing conditions attached to each run. Unknown fields stay unknown. Comparability groups are stricter than development stages. Do not combine changed-target headroom, background-only quality, weighted whole-frame quality, and task quality into a single leaderboard.

Use BD-rate only over overlapping quality ranges from suitable saved rate ladders; do not extrapolate. A single point can establish dominance only when both axes support it under a common protocol. For detector-based demo metrics inspect encoder/judge dependence, detection-conditioned subsets, resolution transforms and missed detections. Preserve historical metrics and verdicts when adding separately labeled derived analyses.

## Provenance and coverage

Original host:path locations remain canonical. Recovered Git histories, small snapshots and extracts are outside the code tree. Committed records contain lightweight inventories, hashes, original locations and analysis. Shared NFS mount identity, not per-host device numbers, identifies duplicate storage. Every inventoried source has a disposition; pending and inaccessible sources remain coverage gaps. The audit must not claim exhaustive scientific verification from exhaustive filename enumeration.

## Delegation

Sol leads use gpt-6.1-sol / low. Their extraction workers use gpt-6-luna / xhigh with bounded briefs and no full-history conversation fork. One lead and up to two workers run per wave under the four-slot limit, with the root coordinator synthesizing between waves. Individual domain records report actual delegation and access outcomes.
