## How dispositions propagate

The commit, PR, manuscript, demo, session and experiment indexes are the authoritative per-source registers. A grouped net-PR or stage analysis can coexist with `individual_diff_review=false`; a mechanical merge or equivalent patch is not another experiment. A source identity may be analyzed while its scientific use remains pending.

The 179-family server source map is the parent register for deeper metadata-only pointers and candidate artifacts. A file with no content card inherits **pending scientific verification** from that source group; copying/hashing alone does not promote it. Duplicates retain their original locations and content identities. Pruned media, weights and raw streams remain external pointers for later qualification. Metadata counts are lower bounds where pruning occurred. Every missing/inaccessible/pending item remains visible rather than disappearing from a successful-search total.

Retained deleted-branch tips, archive tags and stashes are recoverable objects. Unnamed/unretained deleted refs and garbage-collected objects cannot be searched from the recovered union; no claim of full historical resurrection is made. Likewise, successful Overleaf Git access does not expose unsaved editor state.

## Negative searches and corrected audit errors

Sandbox DNS failures were followed by successful authorized network reads; they were not treated as source absence. GitHub's restricted tags endpoint was replaced with Git transport. GPU4 remains locked. Two bounded archive-recursion attempts were incomplete, and relevant selected-report size limits were resolved by targeted follow-up copies. Initial fleet parsing falsely looked for dispatch only in run directories; corrected snapshot-root parsing supplies the retained counts. Initial source-map status labels were reconciled to completed recursive metadata. Code/manuscript worker transcription and arithmetic errors were corrected against their primary source before promotion. [Coordinator notes](records/coordinator-search-notes.json), [server search log](records/server/search-log.json), domain validation records.

## Retention and scope

Recovered Git bundles remain in the shared audit folder; the final selected-source archive is retained locally outside Git. Exact locations and verified hashes are in [retention](records/retention.json). Its 775 selected members were independently read from the archive and checked against the embedded manifest. Approval review rejected that archive’s GPU3 upload, so no upload was retried or performed indirectly. The working `/private/tmp` cache is a convenience, not the durable source. Original code, paper copies, datasets, checkpoints, experiments, running jobs and user-owned worktrees were not modified or cleaned. The scoped dossier branch contains lightweight indexes, source references, derived CPU analysis and prose; manuscript integration and new experiments require a separate task.
