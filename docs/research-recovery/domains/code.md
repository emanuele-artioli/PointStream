## Read the stages by behavior, not by calendar

| Stage | Actual processing question | Comparability boundary |
|---|---|---|
| Original application and object pipeline | Server/client, extraction, scene metadata, configuration and object-centric processing become executable infrastructure. | Application completeness, successful parsing or unit checks support implementation only. They do not prove transported-rate advantage or independent decoder quality. |
| Generative/object reconstruction development | Appearance references, pose/segmentation conditioning, model adapters and residual steering test how a receiver could reconstruct objects. | Checkpoint, fine-tuning exposure, target/reference identity, temporal API and perceptual-metric version must match. Legacy invalid conditioning/metrics cannot be pooled with repaired runs. |
| Conventional foreground-removal/headroom diagnostic | Encode a changed target with foreground removed and compare its conventional coding cost with source. | This is a positive opportunity diagnostic under tested masks/anchors. It changes the coding target and does not pay reconstruction of removed objects; it is not a PointStream full-source win. |
| Background plate/registration experiments | Explore plate selection, panoramas, warps, deltas and residual cost under increasingly explicit charging. | Source-derived client plates/caches invalidate source-free transport claims. Cold initialization, refresh and recurring costs must all be priced; smaller plate cost alone cannot establish duration crossing. |
| Competitive Gate A/B and table-derived modular ladders | Candidate tables, regional weights and anchor caps propose an operating point and confirmation rules. | A static/table-supplied score, grey strip or gate label is not an encoding measurement. Unsupported pass claims are retired; fair access/anchor and provenance audits are separate work. |
| Measured modular background/foreground campaign | Real codec wrapper paths, object color/alpha/crop/pose streams and cached reconstructions isolate rate-quality bottlenecks. | A component or 16/48-frame development screen has its own source exposure, accounting and client assumptions. More quality at much greater bytes is not a capped win; a losing checkpoint screen is not universal model failure. |
| Short-lived JE journal branch | Silhouette rate probes, regional error decomposition and native AV1 object color assembly promote one nominal Alcaraz point. | JE10 retains source tracks/cached background in reconstruction; JE11 repeats costs analytically. Nominal arithmetic is recoverable, but full fresh-client victory and match persistence are invalidated/retracted. Future valid codec outcome remains unresolved. |
| Shared SAM3.1/pose and demo pivot | Unified perception payloads, RTMPose hand representations, factory-background fill and oracle mask screens organize future conditioning and presentation. | Oracle maps and coverage are diagnostics; inactive/failing pilots are not qualified training. Demo clip/model identity and encoder/judge coupling require explicit scope. Wrong-clip risk is unresolved rather than a proven replacement result. |
| September 28–29 research rebuild | The pinned ten-chapter package reconciles old claims, preparation and experiments. | Documentation audit is a useful authority for retiring claims and locating sources; it is not a newly replicated experiment. |

These stages overlap on branches. A new experiment ID or calendar date does not make a protocol comparable: preserve source/window/frame identities, encoder access, adaptation and deployed model bytes, full stream envelope, fresh decoder inputs, metric implementation/regions and hardware/timing scope. A prospective experiment plan should remain visibly prospective until its artifacts satisfy those conditions.

## The key correction chain

Three distinct changes must remain distinct. The conventional headroom measurements motivate recovering foreground without spending its entire conventional cost. Later modular candidates test that possibility and have documented negative capped outcomes. Finally, remote journal prose promotes a tiny nominal one-point byte margin into full-wire and session claims before establishing fresh-client reconstruction. The recovered JE10 source really invokes AV1 for color, but reuses background and source tracks; that is a receiver-validation gap, not evidence that the broad algorithm is impossible. The ledger's retirement of the headline is therefore compatible with preserving the candidate arithmetic and its useful component work.

The most consequential source-level negative result is `1a9a90f8339fdd7965c0b2b89a0245823d18ae4c`: its “assemble winning codec” subject changes only documentation. Runner code arrives in `a4f603729e7ab7ac78800ed1142b49dfd5cbb153`. `3725388ebadb14f09c046657082d187b7735786d` later marks match persistence complete by multiplying one point's recurring costs, replacing a plan that expressly required real consecutive intervals. These findings explain why archived claims must retain both their first appearance and later correction.

## Source coverage and limitations

Primary sources are the immutable bare repository and local GitHub API captures: full PR metadata/bodies; issue coverage showing that the 149 issue entries are all PRs; conversation captures for PR12,34,104,108,109,111; and 19 global inline review comments. A lack of other conversation records is a transparent negative search, not evidence that no discussion occurred elsewhere. The review uses the pinned prior package as a lead and correction source and checks substantive code diffs where cards say so. Prototype coverage includes 179 commits after the initial root through March 25, 2026 (180 inclusive), with full changed-path/stat triage and high-signal implementation/report cards. No source checkout or active Cursor work was modified; no GPU jobs, cleanup scripts, worktree archive or experimental reruns were performed.

Public-reachable commits may be cited at GitHub with their exact SHA. Recovered-only commits must instead cite their retention inventory and bundle/bare-object provenance; public URL accessibility is not assumed. External artifact paths remain historical source references until hashes, native versions, actual decoded inputs and protocols are independently certified. Tests mentioned in historical PRs establish only their tested behavior, not scientific success.
