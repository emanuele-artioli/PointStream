## The comparisons that currently cannot be pooled

`demo_streams.json` names `factory035_close_hands.mp4` for clip01, while timestamped comparison and RTM reports and older website filenames use `factory001_worker001_00001`. The recovered at-risk branch recognizes that older factory001 reconstruction may be the wrong basis. Neither a shared `clip_01` key nor a filename proves matching input windows, source frames, exposure or transforms. Data/source fingerprints and native decode verification are missing comparisons, not inferred replacements.

The benchmark's default RTM input observations and reconstructed MediaPipe judge are different measurement systems. This backend mismatch differs from the true same-model circularity in the archived pairwise judge screen and privileged-mask oracle. Specifically, detection is matched hands divided by RTM-reference detected hand instances; MPJPE averages matched hands only. The pitch ceiling is frames with at least one reference detection divided by all frames. Detection-conditioned hand-instance denominators cannot be divided by the pitch's nonempty-frame fraction to create a “fraction of oracle ceiling.” Missing encoder detections, missed decoded frames and association differences must remain visible; counts should include the entire registered window and independently annotated source truth. The map path labeled SAM3.1 actually loads `sam3.pt` via frame-wise Ultralytics SAM and states that the multiplex SAM3.1 checkpoint is unavailable; no SAM map payload is retained. This must be separated from the pinned true SAM3.1 multiplex tennis results. The map screen also carries a 300-frame/10-second index beside copied 48-frame/1.6-second sidecars, so these cannot form a common rate ladder without original identity reconciliation.

The default background encoding disables hand masking and retains source hand pixels. The hand renderer's coordinates originate from raw poses rather than a decoded packet, while the packet serializes x/y and reconstructs z as zero. This narrows the current demonstration to a source-assisted visualization rather than a fresh receiver proof that hand information was independently transported and recovered. Full package reconstruction, not component byte arithmetic, is the relevant next comparison.

Reported bitrate sums background, landmarks and an amortized anchor, while per-clip `total_bytes` charges a full shared anchor repeatedly. The actual physical envelope and the permitted anchor reuse/session horizon must decide the rate; there is no defensible choice simply because one sum is more favorable. Likewise fixed/dummy latency terms cannot support end-to-end real-time claims.
