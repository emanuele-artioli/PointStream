# Card: W8 fresh-decoder witness (proposed, not authorized)

**Goal.** Test whether the frozen W7 scale-4 hybrid for one specified window can be reconstructed by a fresh receiver from a complete, actually serialized payload and explicitly installed decoder models, at a rate that still supports a narrowly defined single-window player comparison. This is a feasibility witness; it does not claim a complete codec win, Tier 2 success, 240-frame coverage, reference reuse, live operation or generalization.

**Requested new authority for later review:** at most **3,600 GPU-seconds and 3,600 workload CPU-seconds total**, including all setup, failed smokes, validation and publication attributable to this proposal; zero training, model changes or downloads. No implementation, job, spending or new authorization is implied by this card. Existing data and artifacts stay immutable; write a separate identified run. A failure, unresolved rate comparison, cap exhaustion or inadequate projection stops the work; no automatic retry or borrowed budget. The root reviews this proposal before any budget question or execution.

## Scope and frozen inputs

Propose `nad000`, `nadal_kyrgios/000@120`, 240 native frames at 50 fps (4.8 s), its original W7 scale-4 operating point and **only its 80 saved ticks** (`0:240:3`). This is a single previously evaluated window, selected because its complete W7 native and accepted repaired anchor evidence exists, not a new untouched trial. Fix the candidate before reading any new witness output. Use the exact existing generator and tennis base, Nadal–Kyrgios match adapter and pose guider, SAM receiver, native SVT-AV1 base, decoded KPS2, reference crop and compositing recipe; preserve 30 DDIM steps, guidance 2, 24/4 context, run boundaries and seeds. Generate all conditioning frames required by the original full runs, retaining the 80 original output ticks: synthesizing only 80 input poses would change temporal context. No source-derived original RGB, source target masks or prepared/golden arrays may be accessible to the decoding workers.

Before a runnable spec, independently resolve and SHA-256-pin the exact transport and its `.ref` and KPS2 members, scale-4 IVF and native decoder/version, tensor checkpoint and original guider/base, code and packed environments, full configuration, original source/anchor provenance and golden crop/mask/base/composite/score archives. Existing leads: W7 preparation `20261031T162058Z-c9b2c47b` archive `94a5d6318fc113557fb24c8a32f2edffdf368f7a289484fddd4b19a749302bfa`; generation `20261031T163512Z-1d0712ad` archive `cce89567a57bd202db8dbd6a39599688bce8a52e048d53f2b38fd7fda7da4985`; receiver `20261031T173041Z-afee870c` archive `a60cd08a254945a7f0f180b7ba783dda1b127814ba9f4c0ac04d1333758d4ba7`; judge `20261031T180054Z-b9927a25` archive `bf05e2630d898a2ec68452f81407e063b0f0ad0490365c41d53a3988f5adb299`. Original input identities must be verified, not inferred from these output hashes. The prepared and golden archives are allowed only in the independent CPU oracle or offline validator, never the receiver.

## Gate 1: CPU payload and input oracle — before any GPU

Use isolated host-local scratch and existing packed environment/worker interfaces to construct the proposed **actual, self-delimiting** candidate payload: native IVF; KPS2; both selected `.ref` packets; a serialized quantized match adapter/guider with every required tensor identity, shape, dtype, scale, compressed-body boundary and integrity check either encoded or unambiguously fixed by the declared decoder schema; and all required profile/model identifiers, synchronization, units, versioning and mux framing. Do not count research debug files or alternative JPEG encodings as wire. The two reference crops are actual per-window assets, not proof of the 12-crop reuse model. Explicitly declare installed generic weights, tennis base, SAM model and software identities separately from content-specific bytes.

In a fresh CPU decoder, with independently staged golden arrays available only to the validator, require: exact payload lengths/stream boundaries and hashes; exact decoded reference RGB and unit/reference-tick/box binding; exact KPS2 times, run boundaries, q4 keypoints and visibility; exact recomputed box geometry and pose-map arrays against saved prepared inputs on all required run frames; exact quantized adapter and guider integer symbols, per-tensor scales/metadata and dequantized tensor bytes versus the frozen generation input. Verify all names and shapes, no extra/missing tensors, and reproduce generation profile, seeds, ordering and fallback. This is an input oracle for the same recipe, not a substitute for generating output. Fail closed on missing or ambiguous identity, wrong base/model, overflow, mismatch, or hidden source/prepared dependency. If the proposed format cannot be built and checked within the CPU cap, stop and report; do not switch precision, model, references or crop policy.

Count exact delivered bits once by unit: per-frame KPS/base and any correction streams; per-window framing and references; per-match adapter/guider; one-time decoder installation and model lineage. Report **cold-start** actual single-window bytes/4.8 s, **warm** marginal bytes only when a precise preexisting-cache contract and object identities are specified, and the explicitly conditional **7,200 s** accounting scenario for the exact delivered match/reference objects; do not claim their two-hour reuse or corresponding quality was demonstrated. Include prior counted JSON/KPS/reference framing only once, replacing modeled terms with measured packet bytes rather than adding them again. Installation costs and a content-specific tennis-base sensitivity are reported separately, with explicit amortization horizons.

**Pre-GPU decision rule:** at the actual candidate payload rate in the stated conditional 7,200 s scenario, compare the frozen original `nad000` player LPIPS and DISTS to each of the four accepted W7 anchor families via the same log-rate interpolation, only inside each measured rate bracket, with no extrapolation. Both metrics must be strictly better than every family for this one window, and all four families must bracket the rate; otherwise stop before GPU as failed or unresolved, respectively. The unrepaired historical rate or tier-level omitted-family sensitivity cannot substitute. Frozen corrected-2h W9 record is `docs/experiments/w9-inputs/w7-repaired-2h.json` SHA-256 `5245d83df6f8ee16ade28174f6f3c46a94b42ae4d32520c2165fa602e83e9d86`; it records nad000 44.6181578 kbps before this new actual-payload accounting and DCVC bracket 36.825–49.7783 kbps. Recompute all four bounds and gaps from the SHA-identified accepted raw points, not from rounded display values. This saved-quality rate gate is only an optimistic accounting screen: even a pass cannot certify quality until the receiver reproduces it, and the assumed 7,200 s reuse remains conditional. Record how much rate headroom remains and its units; no fabricated overhead or hidden base-installation assumption.

## Gate 2: staged real receiver and verification — only after Gate 1 passes

In new, access-audited worker processes, supply only the counted bundle, explicitly installed SHA-pinned model/configuration files and declared runtime libraries. Use the existing **separate packed environments and narrow interfaces** for generator, SAM and native-base/score stages; first audit their exact locks, CUDA/decoder paths and compatibility, never assume one merged environment. Transfer only decoded inputs and newly generated artifacts between workers. Prove isolation through a negative read test for original source, target masks, prepared/golden and result directories, including mounted files and enabled tools; if enforcement is unavailable use attended execution with verified equivalent isolation, otherwise stop. Preserve source-free fresh process inputs and access trace.

Smoke uses a valid whole sampler context/run and both player units, with the original sampling/seed policy, real decoder/base, SAM and composition, and a substantive validator; at most **500 GPU-s** total for all smoke work (and never more than 600 s in any smoke). Its output is only infrastructure evidence. Require actual device, kernels and installed model identity, correct context and no forbidden reads. Compare the measured pilot cost plus staging, process setup, final validation and publication with remaining cap before promoting. For context-dependent generation, a truncated run is not asserted identical to a full-run golden; a representative full-context pilot must preserve the original sampler semantics. Record per-stage completed item checkpoints and stop rather than extrapolating beyond the cap.

After full fresh generation and receiver masks are sealed, a **separate offline validator** may read the immutable golden data and original source/score masks solely to judge the sealed output. Predeclared gates: exact reference/pose/geometry/tensor inputs and native decoded-base bytes against the same CPU/GPU conversion path; prefer byte-identical generated RGB, masks and composited RGB at every saved tick. If generated RGB differs, accept the numerical fallback only when every channel differs by at most one 8-bit level, the projected binary masks are bit-identical, every composite channel differs by at most one level, and each paired per-tick and mean player **and** whole-frame LPIPS and DISTS differs by at most 0.001 from the saved golden. That 0.001 is a prospective platform-tolerance gate, not a claim of exact reproducibility; changing it after seeing output is prohibited. A missing golden, unmeasurable metric, violation or source access fails the witness rather than waiving a check. Report per-frame maximum differences, hashes, score differences and exact vs numerical status. A passing 80-tick receiver plus rate screen supports only this one-window witness under its declared paid/installed assets.

## Feasibility, cap and stop

Rough prior context, not a reservation or performance guarantee: original nad000 two-player generation on Ada was smoke 66.91 + full 1,231.66 GPU-s (`1d0712ad`); SAM receiver smoke 77.19 + full 229.07 GPU-s (`afee870c`, shared); W7 judge smoke 32.53 + full 203.25 GPU-s (`b9927a25`, shared). W6 match5 on shared A6000 used about 1,908 full GPU-s for two 240-frame units, and the model–GPU table records its CUDA/flash checks there. W7's 80 saved ticks still came from full-run generation. Other new costs—payload decode, process startup, isolation, fresh-device determinism, validated model installation, native base and publication—are not in that simple sum. These heterogeneous records do not prove a 3,600-second fit; a representative pilot must establish it. Select only a model/GPU class with the project's recorded qualification; if a new class or changed kernel configuration is required, its within-budget smoke must establish the full device/provider/kernel checks or stop.

Planning envelope, not guaranteed reservation: ≤500 GPU-s smoke; ≤2,200 generation; ≤450 receiver inference; ≤250 scoring/validation; ≤200 setup/publication/contingency = 3,600 GPU-s. Every actual attempt and worker admission is charged, including failed smoke and any repeated inference; transfer unspent amounts between stages only after a recorded scale projection. CPU oracle, attributable staging, validator and publication share the separate 3,600 workload CPU-s cap, including GPU-stage CPU companions and child processes. Record parent/child resource usage per stage and handle cumulative snapshots without undercounting; long-lived fleet infrastructure is excluded. Establish an enforceable workload CPU bound before dispatch. Every stage/wait ≤45 min; fleet jobs use `scripts/ps-fleet`, ≤600 s smoke, substantive validators, SHA-identified staged archives, packed environments, declared deadline and budget; inspect all eligible hosts and existing tasks before submission and never replay an uncertain job. If projection, CPU rate gate, input equivalence, isolation, identity, finite measurements, or reproduction gate fails, retain artifacts and report the exact stopped stage. If no full path fits, report the measured narrow result and ask for a separately reviewed revision, never overrun.
