# Source-only reference preparation for the combined-development rally

Before viewing proposal overlays, take the midpoint of each consecutive 20-frame bin in the fixed Nadal–Kyrgios 240-frame source (10, 30, …, 230). Keep every fourth selected frame unprompted, starting with the first. Export source images and, for the other nine frames, the two existing body-mask proposals by identity, separate detected racket proposals and the automatic ball center if the tracker returned one. Body masks come from the original source SAM archive, before the historical attachment of touching rackets. All corrections and uncertain, absent or missed objects require human judgment against the source. This package checks input availability and makes annotation possible. It does not create an independent evaluation or authorize promoting a model prediction to a reference.

The archive contains all 12 native source images. Nine have separate proposal layers for the players’ bodies, available racket detections and raw ball center predictions. The other three contain source imagery only. Original source masks were drawn on a 960×540 grid and expanded with the project's nearest-neighbor rule. Every exported mask and source image passed a 1920×1080 dimension and lossless PNG round-trip check. Zero frames have a human reference decision in this export.
