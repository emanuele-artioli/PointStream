## Results

Both encodes used the same input and codec settings. The source-preserving base was 182,055 bytes and the cleaned base was 144,383 bytes, a saving of 37,672 bytes (20.69% of the base). Counting the existing 571,630-byte player, manifest, original base and ball delivery, replacement with the cleaned base gives a **533,958-byte, 889.93 kbps modeled delivery**, 6.59% fewer bytes. This sum uses the already authenticated carrier and ball framing. This number models the PNG-reference carrier, with the previously delivered PNG references charged in full. The presentation video is a separate H.264 viewing encode. A subsequent campus CPU check rebuilt and validated a complete clean delivery using lossless WebP references. That serialized player packet, manifest and rebound ball sidecar total **410,704 bytes, or 684.51 kbps**, versus **448,376 bytes, or 747.29 kbps**, for the corresponding full-source-base WebP delivery. The savings remain 37,672 bytes, or 8.40% of the complete WebP delivery. The campus check validated the channel payloads and did not rerun GPU player generation. ## Tighter sender-mask refinement

The subsequent GrabCut-based sender mask generated a 147,684-byte base at the same codec settings. The untouched base again matched the earlier 182,055-byte native stream. The existing receiver masks, synthesized players and paid ball tiles were held fixed for the full 240-frame [paired video](</Users/manu/.codex/visualizations/2026/11/18/01a1edc1-dd4e-7ab3-b819-fbd88da8db05/clean-court-rally-20261118/grabcut-clean-rally.mp4>) and for the 12 exact RGB samples. The clean base remains an opened development result, with estimated delivery cost pending serialization for this variant.

Average RGB MSE in the same predeclared regions was 2110.28 for players, 449.02 for the outside-player boundary, 299.52 for the ball crop, and 45.11 for the complement. The broader-mask pilot scored 2115.25, 584.74, 325.74 and 54.36 respectively. The full-source-base control scored 1661.98, 421.21, 114.21 and 37.76. The tightened masks improve the boundary and complement diagnostics substantially while both variants remain worse than the full-source base in these regions. The sender's frozen coverage and plate-hole gate fails for the refined mask, as documented in the [GrabCut pilot](../clean-court-grabcut-20261119/README.md).
