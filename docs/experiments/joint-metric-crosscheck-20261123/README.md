**Decision.** The competing explanations are recovery of source features versus plausible synthesized detail, imperfect alignment and visible motion inconsistency. Agreement on a support strengthens its interpretation without requiring all objectives to move together. Reversal within one support narrows the reported gain to the metrics that support it. For one fixed native frame per arm confirm source, support and decoded hashes, finite nonidentity metrics, identity controls, and the previous DISTS value within 0.00015. Run the remaining eleven only when a 1.5× projection including initialization fits five local CPU-minutes. Read the prior authenticated native samples. No encoding, rendering, GPU or paid compute.

**Existing evidence.** The historical 65 kbps Nadal experiment already put DISTS and spatial LPIPS on the same 12 reviewed body masks, and observed a metric reversal against the available DCVC-UF operating point. The saved starved-rate motion and PSNR measures compare different spatial or temporal targets. The aggregation below retains those distinctions.

## Reproducing the cross-check

Reopened physical prior-result samples and rechecked the bitstream, 240-frame receiver lineage, every selected decoded image and exact scoring supports. The [input ledger](inputs.json) identifies the original decoder jobs, immutable archives and selected packets. The ordinary and ROI archival frames were confirmed using the original [native AV1 extractor](../shanghai-joint-review-20261122/sample_native_anchors.py) on the warm 640-wide rows of the [control manifest](../test102-joint-anchors-20261122/manifest.json). The neural job's saved 480-wide Q34 output was authenticated using the [four-pass neural extractor](../test127-joint-anchors-20261122/sample_neural.py). These scripts read completed streams and returned only the twelve selected frames. Native AV1/DCVC YUV samples use the established [bicubic display preparation](../shanghai-joint-review-20261122/anchor_frames.py). The original PointStream review PNGs came from published job `20261122T125955Z-4dfede40`, with identity checked by [the joint receiver sample binder](../shanghai-joint-review-20261122/joint_samples.py). No review image is included in the committed results.

Run `score.py --review REVIEW --ball OFFICIAL_CSV --arms ARMS --alex ALEXNET_CHECKPOINT --ticks 1 --out NEW_SMOKE.json`, where the directories under `ARMS` are `joint-crf50`, `ordinary-640-warm`, `roi-640-warm` and `dcvc-480-q34`, each containing `arm.json` and the verified PNGs. Repeat with `--ticks 12` to obtain the full cross-check. The runner imports the existing 1080p source-mask and official ball crop scoring paths. It runs PyTorch 2.8.0, TorchMetrics 1.9.0 and OpenCV 4.10.0 on CPU with two PyTorch threads and one OpenCV thread. Weight and head hashes are recorded in the outputs. The SSIM map uses 11×11 Gaussian windows (σ 1.5), reflection padding and OpenCV 8-bit luma. An SSIM window is evaluated before averaging the map over centers within each mask. MS-SSIM uses the complete RGB frame, standard five weights and separable Gaussian filtering. The initial full-frame TorchMetrics implementation projected above budget. The separable version passed the same nonidentity smoke within 0.000016 of the TorchMetrics score and preserved the metric definition. [One-tick verification](shanghai-smoke.json)

## Interpretation

DISTS measures feature correlations and is designed to tolerate texture resampling. LPIPS compares normalized, learned features spatially. PSNR penalizes the numerical differences between corresponding RGB pixels. Local SSIM uses luminance, contrast and structure on the same image grid. Improvements in appearance can survive a small displacement between the rendered limbs or clothing and the source in a feature metric. A similar displacement still changes aligned pixels. The two body masks average 14,215 pixels, under 0.69% of each full picture. Even after counting the entire 64×64 ball crop separately, the three supports cover under 0.89% of the sampled picture on average. A perceptual win for the foreground can therefore coexist with a whole-picture loss when more bits are spent on objects. These explanations follow from the metrics and measured support. A verified viewer preference would require separate evidence. [DISTS](https://doi.org/10.1109/TPAMI.2020.3045810) · [LPIPS](https://openaccess.thecvf.com/content_cvpr_2018/html/Zhang_The_Unreasonable_Effectiveness_CVPR_2018_paper.html) · [SSIM](https://pubmed.ncbi.nlm.nih.gov/15376593/)

This specifically measures changes between frames. The ordinary arm is 320 wide here, and the fresh spatial suite uses 640-wide AV1.
