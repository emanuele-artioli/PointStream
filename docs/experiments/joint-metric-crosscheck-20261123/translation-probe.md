# Are small shifts part of the foreground pixel-error gap?

Use the same four fixed Shanghai packets, twelve instants and actual decoded images as the metric table. Within each original player mask and official ball crop, fit one translation of at most six original pixels along each axis. Fit luminance on one checkerboard parity and measure RGB squared error on the other. Bound the support once before fitting so all allowed offsets use the same original target pixels. Zero offset is always allowed. Report the change in mean RGB squared error and displacement magnitude separately for bodies and ball and by codec. The result is a diagnostic on unchanged outputs. If PointStream recovers more error on the held-back pixels, modest departures from exact pixel alignment plausibly explain part of the PSNR gap. A residual gap or a small recovery points to other differences such as shape, color, texture, blur or masking. Do not select test ticks or publish these scores as the standard PSNR endpoint. Reuse authenticated samples. Time cap two local CPU-minutes, zero GPU and no network reads.

The bounded translation reduced PointStream’s mean squared RGB error by 9.86% on the body masks and 10.87% on the ball crops. The corresponding reductions for ordinary AV1, ROI AV1 and DCVC-UF were 5.84%/1.57%, 5.40%/0.98% and 4.45%/2.43%. On both supports PointStream’s residual error remained higher than the ordinary and neural controls. Small shifts explain part of the learned-metric versus pixel-error disagreement. A single translation leaves other pose, blur, color and boundary differences. All four translation fits use the same maximum shifts, source supports and disjoint fitted/evaluated pixel parities.
