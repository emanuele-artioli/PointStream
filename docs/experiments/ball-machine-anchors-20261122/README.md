# Stronger affordable machine anchors

For each frozen three-match tiled packet under the common 60.6 kbps cap, select independently at each of 640×360 and 1280×720 the available ordinary and ROI encodes that cost no more than that particular tiled packet and have the lowest previously measured ball-crop DISTS within their mode and resolution. Use real raw/zlib-6 wire lengths for every candidate. If none is affordable, report that mode as unavailable. Selection uses already measured visual DISTS and byte counts, not WASB outputs. At each source's unmodified cadence, independently decode each chosen actual IVF, verify both raw stream and decoder hashes, resize to the established 1280×720 judge canvas, and apply the exact frozen WASB 3-frame, stride-1, threshold-0.5 model and online tracker to official source labels. Score 10 native pixels and report labeled-not-visible presence separately; source overlap with the detector's training remains unknown. Compare the existing source/tiled/direct results only if the candidate packet is confirmed byte-identical or separately judged. Sparse open clips, no population estimate.
