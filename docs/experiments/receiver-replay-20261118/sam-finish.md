# Learned receiver, native output and masks

The finisher takes the exact paid carrier, its 625-byte companion manifest, the two freshly generated crop NPZ files and their authenticated generation receipts. The generator's pinned environment performs full JPEG reference decoding and checks the expected RGB hashes. The SAM environment reads the identical hash-verified carrier and strictly checks the native IVF and KPS2 sections. It derives its prompts from the paid geometry. Reference RGB pixels are unnecessary at this stage. The camera base, displayed for every fallback pixel, is decoded with the pinned Linux FFmpeg/libdav1d and checked against the 47,001,600-byte native YUV witness. The manifest is charged once per carrier.

The common receiver launcher invokes `common_player_finish.run` in a source-denied process. The module checks generation job receipts, crop/tick/box/seed identities, assigned GPU identity, model weights, attention backend and live flash execution. SAM uses the W8 production checkpoint and fresh single-frame pose prompts for each active player. Crops are composed in the packet's far-to-near order. Missing pose support, insufficient prompt, empty mask and off-canvas projection retain the decoded base in the corresponding pixels. An absent generated tick, an unbound receipt or a model/native resource failure stops the scientific witness. The four-tick smoke covers 0, 11, 23 and 43. A full witness requires all 240 ticks with per-player coverage and per-frame hashes. `finish.json` gives initialization, native-decode, model-load, per-tick, SAM and finalization time.

The [actual SAM-environment CPU preflight](sam-cpu-geometry.json) ran on gpu5 with GPU disabled for both final JPEG carriers. Each produced 240 valid prompts for each player; the packed SAM OpenCV build differs from the generation OpenCV build. The [isolated native check](../joint-readiness-20261118/isolated-native.json) independently decoded all 240 ticks from the paid packet using Linux FFmpeg/libdav1d under the same launcher's native policy. The [local saved-data compositor check](saved-compositor.json) used real earlier full native-cadence common-player outputs, the paid native base, and 80 archived SAM masks per player from a different generator. All 80 projected composites matched an independent per-pixel implementation exactly. For the remaining 160 ticks the test deliberately omitted masks and every output equalled the native base. This validates projection, ordering and fallback. The live GPU job measures SAM on the new generated crops.
