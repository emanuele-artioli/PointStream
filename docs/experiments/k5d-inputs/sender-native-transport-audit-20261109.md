# K5d sender and direct-native transport audit

Read-only inspection of the 965d801a consumer source and the registered K5d contract found no ground-truth label input to encoded ball positions, presence or rendering choices. The sender runs the fixed BallTrack on source images; its detections seed the track and presence, and the sender fits per-point positions and appearance to source pixels and native decodes. A source-versus-decode pooled PSNR guard can disable BALL for a point. This is source-pixel-assisted sender optimization. The tracker selection saw the retrospective 30-clip cohort; labels are used by source qualification, visible-label crop metrics and the separate scorer, while judges receive rendered full images only.

TrackNet kinds 1/2 are visible, 0 is explicitly absent and 3 is unknown. The scorer excludes unknown frames from negative counts. The frozen 30-clip analysis requires 5,675 frames, including 5,472 visible, 197 absent and 6 unknown, keeps the three historical source failures in the 30-clip denominator, and requires both fixed low-rate comparisons to be supported. The previous 10/197 source-negative calibration remains a failure and blocks a strong absence claim. The 16/48/188 development prefixes do not add independent clips. PCHIP BD-rate uses measured overlapping quality with the registered minimum spans; unsupported ranges remain unsupported.

The registered primary native envelope uses direct native stream bytes; candidates use complete PSBL plus BALL wire bytes. This favors the achievable direct-native anchor and is not equal-wrapper framing. The retained zero-BALL PSBL byte count is available only as an explicitly labeled sensitivity comparison. IVF contains its dimensions, frame rate and frame count and is directly decoded by dav1d. The counted PSDC header contains structure and frame count; the native SPS/NALs contain geometry and coding parameters. DCVC decoding additionally uses the fixed shared HTL/YUV420 convention and installed image/video checkpoints. PSDC does not carry fps; the benchmark fixes 30 fps and the shared color interpretation. Those fixed settings are external installed context, not a claim that PSDC is self-describing for arbitrary playback. No new numerical result or filesystem-isolation claim follows from this audit.
