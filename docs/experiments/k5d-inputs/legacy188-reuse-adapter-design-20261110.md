# Legacy 188 reuse adapter — review-only design

Root accepted the conditional method-family argument in `9a265d86`; this design is **not** reuse admission. Its purpose is to allow the old complete monolithic Clip3 result to enter the existing analysis once, while preserving its old producer identity. It adds no decoding, inference, current-producer marker or replacement of old files. A future root-approved implementation and real current 16-frame qualification must precede any certificate or credit.

## Existing interface and fields

`k5d_benchmark_analysis.summarize(selection, directories)` already expects exactly 30 unique registered output directories, selects one per clip and calls `summarize_clip`. That calls `k5d_encoder.validate`, then reads `pilot.json` and `source-qualification.json`; it uses native/wire bytes, fps and frame count, two arms' per-frame SSE/pixels/PSNR, full/crop LPIPS and DISTS, saved WASB judge counts, source qualification and registered visibility. It computes the existing anchor envelopes and BD-rate rules, never a new inference. Historical failure exclusions and totals (5,675 frames, 197 absent, 5,472 visible, 6 unknown) are hard checks. The recovered old `publish/` contains these fields for all six points and both arms: 188 rows each of the five metrics, including integer SSE and pixels, 188 WASB and BallTrack predictions and scores per arm, source rows and source scores, native/wire/baseline files and receiver receipts. All frames are visible so crop values are populated; old full fps is 30. The actual archive has no retained raw receiver pixels or modern prepare/score checkpoint: its byte and pixel identities are the same-job receipts, independently joined to producer hashes.

`k5d_study_wave.verify_completed` and `validate_full` instead expect the newer exclusive namespace, matching current execution identity, separate prepared publication, coalesced point receipts and assembly. They cannot truthfully accept this old monolithic job by manufacturing those fields. Keep those checks unchanged for modern outputs. A narrow **legacy-only prevalidation** can supply the physically recovered `publish/` directory to the existing analysis after checks; it need not construct a fake prepared publication. First confirm the current `encoder.validate` accepts the old report's actual `188-frame-confirmation` fidelity gate and files; if it does not, identify the exact historical-schema difference and design a distinct validator, never weaken validation globally or edit the saved report.

## Inputs and checks

The adapter takes: (1) the old immutable publication and its `622fd68d5380b97449a09872bc15402117dd9c3e7a2576a757cd6aff8fd090d7` digest; (2) old job `20261105T003756Z-cc450baf` canonical metadata, source archive `48b51fe3b3dbff6e574122ad7ea3aaf0ae5638caef2a69a7170e7e7f8a4d2857`, revision `b26e5b43702a21c37bcb4357223e0e6a25e1bec5`, source `c212f85b429f3a1abbca925de25736334fd06ffe9e821fac7798aaa99703fda7`, runtime `32e68872700e4c3ffbee38425740f5f57ecf6d827a6a05329942c2ac10534661`, spec and exclusive A6000 receipts; (3) frozen selection/label join and original audit; (4) root-approved method-family decision and **actual passing** current 16-frame gate plus current analysis/source/runtime/model/tool bindings, supplied only once independently accepted. Inputs must be pinned by hash and schema, never supplied as a Boolean compatibility assertion alone.

Reject unless the actual old archive and metadata hashes/identities join, the selected clip is exactly full `tracknet/game10/Clip3` with 188 ordered names and matching kind/x/y labels and registered selection identity, and historical source task status remains unchanged. Require the six exact registered point keys, source/manifest/exposure, fps/geometry, full-metrics status, native/PSBL/zero-ball wire byte counts and SHA, PSBL native inclusion, receiver wire/native/resource-map and YUV/rendered hash equality to each old producer receipt. Require all 2,256 ordered arm metric rows with SSE/pixels and finite required visible-frame perceptual fields; validate recorded PSNR and all 4,512 arm judge rows/counts against the source labels, plus 376 source judge rows/counts. The already completed [label join](legacy188-label-method-review-20261110.md) fixes the original TrackNet CSV and members; preserve its scope that JPEG dimensions were not independently checked. Do not create or substitute later receiver outputs.

Check the approved source-family decision against the actual old and current source/archive/runtime and 16-frame gate identities. The old and current specs bind the same TrackNet, BallTrack, WASB, DCVC and metric backbones and packed runtime; the current execution must attest actual native tool identities, metric heads, Python/Torch, GPU/driver and absence of the optional shared allocator profile as identified in [source-chain review](legacy188-source-chain-review-20261110.md). These values cannot be filled from a queued spec or assumed from old results. Preserve exact prior fidelity purpose and calibration exposure; no new success or absence claim follows.

## Minimal certificate and integration

A proposed immutable, versioned JSON certificate (new schema, e.g. `k5d.legacy-monolithic-reuse.v1`) contains: `clip_id`, `frames`, `selection_sha256`, `old_job_id`, `old_revision`, `old_source_sha256`, `old_snapshot_sha256`, `old_spec_sha256`, `old_environment_sha256`, `old_publication_sha256`, `old_fidelity_gate_sha256`, `old_audit_sha256`, `label_join_sha256`, six named per-point native/wire/zero-wire/YUV/render hashes, row-count checks, source/visibility status, and `method_family_decision_sha256`. Separate `current_analysis_identity` and `current_16_gate_sha256` fields bind the actually accepted analysis/runtime gate; include its pinned scientific assets and actual tool/head/profile attestations or a hash to a substantive receipt containing them. `scope` says `old_monolithic_same_job_receiver`, no inferred filesystem denial, and `credit_limit` is one Clip3. The certificate must say *candidate* until root acceptance; the later root approval is separate and hash-binds this exact certificate. No field asserts the old job used the current source.

Put reusable verification in a small new `experiments/tennis/k5d_legacy_reuse.py`; add an explicit legacy-certificate input at the orchestration/analysis boundary rather than routing it through `study_wave.validate_full`. After signature/hash and source-family validation, safely extract the actual old `publish/` read-only into a new caller-owned location and pass that directory once to existing `summarize`. Modern directories retain the existing wave checks; `summarize` remains responsible for the exact 30 distinct IDs and fixed population. Keep a provenance map from the legacy directory to certificate and old job in the final analysis artifact so outputs do not flatten lineage. If `encoder.validate` cannot validate this exact historical output, a dedicated version-aware validator may share existing checks but must explicitly preserve its old fidelity purpose and original receiver evidence; root reviews that narrow exception before implementation.

Meaningful failure tests: mutate old archive or source/metadata SHA; mismatched old/current gate or method decision; wrong frame ordering, label/member or 188 count; missing/duplicate point, altered native/PSBL or receiver YUV/render hash; missing/nonfinite metric or wrong judge row/count; current gate absent or unattested profile/model/tool; fake current producer marker; duplicate Clip3 or omitted historical failure in 30 directories. A positive fixture must use the original old-provenance shape and produce the same existing clip summary without network, codec or model execution. Tests should verify rejection at the appropriate boundary and unchanged denominator; no new numerical outcome or acceptance threshold is introduced.
