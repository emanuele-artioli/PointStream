# Transfer of the Q90 reference setting to another match

The reference figure needs a prospectively fixed second match to test whether the 55.7% reference-byte saving and similar body fidelity on Nadal–Kyrgios persist elsewhere. Use the first 24 consecutive original Alcaraz–Hurkacz ticks (25 fps), both already selected player tracks 004 and 006, identical decoded points, boxes, seeds, common model and 30-step renderer. This is a held-out **reference-setting comparison** on a joint-codec development match. Freeze the lossless reference supplied by the original carrier and AVIF Q90, speed 8, one encoding thread. Never use author markings to select a frame or setting. The eligibility gate is a real two-image Q90 encode that saves at least 30% against the paired source PNG bytes; verify exact lossless reproduction at the local receiver, receipt parity for both complete 240-tick conditioning arrays excluding appearance, and the exact AVIF-decoded RGBs ingested by the learned renderer. A failure closes this transfer test.

Two disjoint 24-tick per-player jobs use the existing native isolated renderer and A6000 class already qualified on this packet. Their smokes render the lossless controls, their full stages render Q90. A separate authenticated staged carrier for each arm contains only decoder-available data. The Q90 carrier holds the exact locally decoded AVIF image in the existing lossless internal format. Actual transmitted image and envelope sizes are accounted separately. Require source denial, stable carrier IDs and original paid conditioning, native GPU/flash and tensor-op kernels, all original output ticks and no missing crops. A 1.5× timing forecast from the matched lossless smoke plus 60 s overhead must fit the Q90 stage and remaining reservation. The two native 240-frame Al028 controls prequalified these identities but cannot substitute for a same-context 24-frame lossless control. Use at most 1,500 GPU-seconds per player including load, validation and teardown, and up to 3,000 campus core-seconds per player; single-CPU jobs, exclusive idle RTX A6000. Prefer the higher-priority joint generalization campaign for GPUs. No paid compute.

Evaluate mean native player-body DISTS (equal person and tick weighting), native body RGB PSNR and actual image sizes. Assess the original dense 24 source-model mask pairs, and the human-reviewed available ticks (including uncertain/absent exclusions). Report how often Q90 improves and any decline. A Q90 DISTS difference within 0.01 absolute of lossless, at ≥30% fewer image bytes, supports a useful rate-saving option on this shot; this is a prespecified engineering tolerance and does not establish perceptual equivalence. This single Q90 setting and one new match close the transfer pilot. Report Q90 as a costly or fidelity-losing alternative there if it fails.
