Use the previously fixed YOLO11x checkpoint `7bc158aa…e773a24`, confidence 0.25, 640 inference, NMS 0.7 and tennis-racket class 38 on **every source frame**. Round its source predicted boxes outwards and clip to 1280×720; retain every prediction and placement. Do not use official labels to choose which frames receive crops. Official labels are sparse: detections at unlabelled ticks are transmitted placements, not proven false positives. On labeled ticks, report prediction/label association and unassociated predictions without asserting that annotations exhaustively label every visible racket.

The gate is a zero-payload source-pixel oracle on the authenticated 61.353 kbps ordinary AV1 base: paste each detected source rectangle, run the same frozen YOLO judge on source and on oracle output, and match predictions one-to-one to official boxes at IoU ≥0.5 (≥0.3 diagnostic). The target is at least 4/6 on source **and** oracle versus the independently established baseline 0/6; fail means stop without building a patch encoder. This tests same-model machine detectability, not independent detector generalization or human racket grip.
