# Dense source-triggered racket crop gate

Freeze the first source by match ID, match209: 64 frames, 25 fps, 2.56 s, six official racket boxes on five sparse ticks. Use the previously fixed YOLO11x checkpoint `7bc158aa…e773a24`, confidence 0.25, 640 inference, NMS 0.7 and tennis-racket class 38 on **every source frame**. Round its source predicted boxes outwards and clip to 1280×720; retain every prediction and placement. Do not use official labels to choose which frames receive crops. Official labels are sparse: detections at unlabelled ticks are transmitted placements, not proven false positives. On labeled ticks, report prediction/label association and unassociated predictions without asserting that annotations exhaustively label every visible racket.

The gate is a zero-payload source-pixel oracle on the authenticated 61.353 kbps ordinary AV1 base: paste each detected source rectangle, run the same frozen YOLO judge on source and on oracle output, and match predictions one-to-one to official boxes at IoU ≥0.5 (≥0.3 diagnostic). The target is at least 4/6 on source **and** oracle versus the independently established baseline 0/6; fail means stop without building a patch encoder. This tests same-model machine detectability, not independent detector generalization or human racket grip.

First use a 16-frame source+base smoke with at least one labeled tick, verify source/decoder/model hashes, real source and oracle processing, and require a 1.5× full 64-frame projected cost below 800 s. Full is bounded to one CPU and ≤1,200 s, zero GPU, with 2 CPU-hours for the entire authorized line. Record all 64 actual source predictions, 64-frame oracle checksum, every labeled hit/miss and source detections at unlabelled ticks. Cost-free source pixels are explicitly an oracle, not a codec.

If this passes, one real 96×96 AV1-tile setting plus actual frame index and source rectangle placements can be tried, using a previously encoded, lower-rate 18.409 kbps plain base to leave budget. The measured return stream must independently decode without source and contain the complete native base, all encoded tiles and placement/container metadata for every detected frame; compare the actual total bitrate near 60.76 kbps (within 1%) and frozen 0.25/IoU 0.5 judge to the strongest affordable existing plain and ROI anchors. The source coordinates do not give dense human labels, so never claim whole-clip recall or false-positive rate. If rate matching or receiver integrity fails, stop; do not infer grip quality. Promising matched performance can motivate frozen, separately identified 235 and 269 confirmation.

The actual 16-frame smoke passed its compute gate: 55.02 s elapsed and 37.01 s measured source-plus-oracle inference. The complete 64-frame CPU run finished in 157.74 s and failed the preregistered quality gate: source **6/6**, ordinary AV1 **0/6**, ideal raw-source rectangle paste **3/6** at IoU ≥0.5, below the required 4/6. The same oracle was **5/6** at the separately reported IoU ≥0.3. There were 70 source-triggered rectangles across all 64 ticks and 59 ticks have no official racket annotations. Two detections on labeled ticks did not associate with any official box at IoU 0.5; because the annotations might be incomplete, they are not established false positives. All 16 smoke source predictions exactly match the first 16 full results.

The tested zero-payload paste is an ideal source-pixel **fidelity** reference for these exact rectangles; it is not a mathematical upper bound on detector recall under lossy coding or larger crops. The specific representation did not pass the frozen gate, so there was no paid tile run, no receiver price and no matched-rate result. To make the possible rate constraint concrete without claiming feasibility: the prior 60.7625 kbps ROI anchor is 19,444 B over 2.56 s, and the saved 18.409375 kbps base is 5,891 B. If each of the 70 placements were encoded in a fixed 10-byte record, 12,853 B would remain for tile data and any packet headers, about 183.6 B per crop before headers. This is only illustrative arithmetic, not an actual transport, codec lower bound, or assumption that placements cannot be coded more compactly. A separate proposal could freeze a contextual crop/alternative detector rule and repeat the no-cost oracle before any encoder.
