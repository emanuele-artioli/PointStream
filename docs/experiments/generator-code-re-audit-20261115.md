# Experiments: generator code re-audit

### 2026-11-15 — historical K6b AnimateAnyone implementation

**Scope and conclusion.** Read the actual generic inference and preparation at `47db732e`, the match/base fit at `45b9b90`, and the current `experiments/tennis/k6b.py`, `k6b_generate.py`, and `k6b_fit.py` (the current generation changes after 47db732 add fit/base/CFG and output options; the generic image path remains). This is a source audit, not a rerun, a full audit of the external AnimateAnyone pipeline, or independent verification of the archived input/checkpoint manifests. No model, GPU job, or raw evidence was modified. The results remain useful as **bounded comparisons of these implementations**; they do not establish a general ceiling for pose-driven animation or clean unseen-match transfer. The previous agent's model is not evidence for or against correctness.

**Concrete defects and interpretation.**

1. Fit seeds collide: `k6b_fit.py:379–381` at `45b9b90` computes little-endian bytes modulo 2^31, retaining essentially the first four characters. A local Python reproduction gives `alcaraz_hurkacz__036` and `alcaraz_hurkacz__045` the same seed, 1633905761. This does not corrupt either fit or prove the historical ranking wrong, but it defeats independent name-derived seeds; one stochastic fit and one generation seed cannot establish robustness. Generation uses SHA256 of the unit name plus run (`k6b_generate.py:257,270`), deliberately paired across profiles. **Minimal check:** a CPU test of seed uniqueness on the actual manifest, then paired multiple independent fit/render seeds on a small predeclared representative subset if stochastic robustness matters; no retrospective selection of the best seed.
2. `k6b.py:584–590,620–623` permits `finetuned_tennis` missing units to fall back to original; the latter line also silently falls back for any missing per-frame profile key, and skips a player entirely if neither key exists. A missing crop or crop rectangle can therefore change the measured method or leave target-derived Telea fill within the granted region. This is a code-path defect in strict attribution/coverage, not evidence that the historical jobs actually triggered it. Inspect the historical generated `(unit, profile, t)` joins and per-frame written-mask coverage against the exact judge manifest. **Minimal check:** offline receipt join and a fixture that deletes one fitted tick and asserts failure rather than substitution; recompute affected cells if any, preserving originals. `k6b_generate.py:338–339` checks shape/non-flatness, not completeness or attribution.
3. Model checkpoint join is explicit but not semantically guarded: `k6b_generate.py:215–250` maps caller-supplied profile names to files, not unit/match identities; `k6b_fit.py:134–191` checks LoRA key presence/merges, not that a match adapter belongs to the evaluated match or was trained on the recorded base. Its generation receipt hashes the fit and `apply_fit` records the base hash. This is a validation gap, not proof of a wrong join. **Minimal check:** join saved generation receipts' hashes and profile labels to fit receipts' match, selected windows, base SHA and billed bits for all six windows. Check training source hashes and duplicate or overlapping source intervals, not just different window names. Archives are needed for this audit.

**Conditioning and implementation boundaries.**

- `k6b.py:128–198,293–320` computes fixed-aspect 512×784 boxes at a 1.4 margin and 90th percentile run height, 9-frame centred smoothing, with pixel rounding shared by image and pose transform. Upscaling, hard black padding outside the image, and clipping bodies at extreme sizes are real distribution shifts; inference boxes use coded pose whereas fitting boxes use uncoded pose (`k6b.py:351–372,398–435`). The percentile and smoothing use future poses in each run: valid for the offline oracle but not evidence of a causal live codec without delay/buffering. **Minimal check:** compare transformed keypoints against synthetic corner/round-trip coordinates and count source-region/matte outside rectangles for each saved evaluated frame; compare causal and offline geometry if streaming is claimed.
- The reference is the first fitted scored target-window crop, from uncoded true pose and source RGB (`k6b.py:302–308`); it can be a judged frame. Exact target-region masks and background fill are granted by the oracle (`k6b.py:599–623`). They are not unintended training leakage, but give target information and are not a complete paid decoder. The nominal held-out pilot with `--from-t` excludes those target frames from fitting yet can still condition on an earlier same-window reference; temporal proximity and appearance information persist. **Minimal check:** enumerate reference timestamps against judged ticks and fit windows; test an externally supplied, actually coded reference and receiver-available mask in a new independently specified experiment.
- Body-only COCO-17 points are converted to OpenPose-18 with derived neck, confidence 0.5 and 17 colored limbs (`k6b.py:79–123`); hands, face and racket are absent. The output uses RGB `Image.fromarray`, while training uses RGB crop VAE input divided by 127.5 minus 1 and CLIP processor defaults, and pose divided by 255 (`k6b_generate.py:169–178`; `k6b_fit.py:258–274,399–404`). Source conversion calls `rgb_memmap` after source SHA identity check (`k6b.py:273–286`). This supports intended channel/range consistency but **does not prove** pixel-identical behavior with the archived external fork's pose drawing, CLIP/VAE preprocessing or full model pipeline. Pose/reference distribution shifts could disadvantage both generic and fitted methods. **Minimal check:** on the pinned external code, compare body-only rendered maps pixelwise on synthetic asymmetric colored joints, plus source RGB, VAE, CLIP and pose tensors at train/inference boundaries. Confirm the exact archived dependencies and transforms before concluding parity.
- Each consecutive coded-pose run is generated separately with its own deterministic seed, 24-frame context and overlap 4 (`k6b.py:219–228`; `k6b_generate.py:169–177,261–270`); all poses in each run are supplied, but only judged frames are ordinarily saved. Run fragmentation resets temporal context and stochastic state; the actual FPS is not passed to the generator. These are real conditions, not proven wiring bugs. **Minimal check:** verify source-to-pose timestamp/fps and run length histograms from receipts, and compare one fixed short contiguous sequence with and without an artificial run break under matched seeds; evaluate motion at native cadence as well as judged ticks.
- VAE and CLIP use `from_pretrained` with loading records; UNet and pose-guider state loads check missing keys, permitting the unused reference output head, and motion weights are overlaid on denoising weights (`k6b_generate.py:79–114,135–160`). Fitting uses original weights, VAE normalization, random same-unit reference/target pairs, velocity prediction, and a frozen motion module (`k6b_fit.py:197–254,258–295,399–404`). The inference model uses temporal motion conditioning while training is single-frame, and reference pairs may select the identical frame. These are training/inference differences and potential shortcuts, not demonstrated failures. Verify archived fork's reference attention and scheduler transforms directly, check missing **and unexpected** key receipts and base/adapter numerical merge equivalence. The held-out pilot's loss/probe checks alone do not validate generation quality.

**Evidence use.** The generic 3/6-per-metric result is a credible prioritization signal for this exact granted-input recipe, subject to saved-join and coverage checks; it cannot rule out improved conditioning or a newer generator. The in-window rank-64 result is explicitly a seen-frame, unbilled upper-bound-style experiment, not transfer; calling it a universal upper bound is unwarranted. The rank-4 match and cumulative tennis-base/match outcomes are useful comparisons of those specific data, selection, checkpoint and billing settings, conditional on the receipt joins above; they do not isolate base, guider or training data effects. The existing same-broadcast confirmation is not clean independent-match evidence (see `k6b-players.md` and `submission-player-model-history-audit-20261115.md`). A new claim that contemporary generation fails in general, or that fitting cannot transfer to unseen matches, needs a predeclared contemporary replay with verified independent source/match splits, coded references and receiver-available masks, paired seeds, and strict generation/conditioning joins. A broad replay is not justified solely by the seed collision or these unverified failure paths.
