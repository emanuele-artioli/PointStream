# Match-weighted readout

Choose streams on realized bytes and the frozen policy before reading target quality. Run `aggregate.py MANIFEST RECORDS OUTPUT` separately for each bandwidth and cache policy. An input record names `event_id`, `rally_id`, the display `route` (`joint`, `ball` or `conventional`), the paid `byte_ceiling`, and every decoded native source `tick`. It records one physical charge and SHA256 per `pointstream`, `av1` and `dcvc_uf` stream. The scene-selective entry names its delivered `fallback_codec` when the route is conventional. The `supports` object binds each region and transition set by SHA256. Every stream's `scores` uses those region names. A missing measurement uses `null`. Use metric names from the script and preserve the raw scores, native packet and region ledgers with the result.

The output always counts every enrolled rally, actual route and unresolved delivery. It emits a pooled quality estimate only when every enrolled interval has three real deliveries and all compared streams have the relevant common support and metric. Improvement is signed so positive values favor PointStream. Give each rally equal weight within match, then each match equal weight. Preserve all six signed effects, the held-out effects, and a paired whole-match bootstrap. With six independent matches the interval is descriptive. Report only the common quality range for BD-rate over the full physical ladders, as a separate calculation. Multiple operating points from one delivered sequence add no new matches.
