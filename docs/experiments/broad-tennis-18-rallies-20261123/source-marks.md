# Independent source marks on the held-out points

Freeze eight scoring instants per point before opening any reconstructed frame. Divide each original point into eight equally spaced time bins and select the native tick at floor((2j+1)N/16), j = 0,…,7. Retain every tick, including broadcasts that cut to a close-up. If an entire conventionally routed shot has no selected tick, add its native midpoint as a separately flagged diagnostic. Keep this extra sample outside the equal-bin aggregate. Enroll the same original frames for every codec and budget. Existing original start/mid/end inspections informed source authentication only.

The private packet presents each original frame at its native 1280×720, with a magnifier. Draw a polygon around the visible body and clothing of each named singles athlete, excluding equipment, shadows, officials and other people. Record the ball centre when visible. For each body and ball, distinguish a visible mark, absent from the picture and uncertain. Keep all statuses. The two players have fixed names throughout the match, including close-ups and changeovers. Native frame, source and pixel identities, selected time-bin and routed interval are recorded separately from the editor. Source marks will support a future body-silhouette endpoint and visible/absent ball analysis once completed. An empty packet supplies no labels or accuracy results.

The packet contains 48 source PNGs across six independent, offline point pages. The fixed grid sampled 40 court frames and eight conventionally routed frames. Every routed shot is represented, so no diagnostic top-up frame was needed. [Frozen source identities and route-stratum counts](source-marks.json)

Within the private packet, open `index.html`. Each point has a separate export. Import that export with `python tools/datasets/al028_review_import.py --review POINT_PAGE_DIRECTORY --decisions EXPORTED_JSON --out NEW_OUTPUT_DIRECTORY`. The normalized record contains original broadcast and extract SHA256s, local and absolute native ticks, source RGB hashes, named-athlete pixel masks and ball coordinates on the 1280×720 original grid. Visible body marks require at least one nondegenerate polygon. A visible ball requires an in-bounds coordinate; absence and uncertainty preserve a null coordinate. Score compared displays at these exact source instants. Give missing/uncertain counts next to each endpoint, and present ball false positives on explicitly absent frames separately.

The private master page is `tenniset-source-marks-20261123/index.html` in the project’s author visualization directory. Six per-point contact sheets sit beside their editors. A synthetic offline browser round trip exercised polygon drawing, native ball marking, absence, uncertainty, export and import. These synthetic decisions were discarded; no reviewer decisions were solicited or imported into the paper.
