## Results

The court-geometry selector found both cuts at the source-frame boundaries and routed **100 court / 45 non-court / 100 court frames** (2.00 / 0.90 / 2.00 s). All 200 court frames agreed with the two previously human-marked shots. The other 45 frames show a player close-up on source-only inspection by the agent. No independent human active-play timing or close-up label was available for this passage. The whole-broadcast historical motion selector classified these same spans **other / interlude / point**. It took the conventional path for the first two spans. Eligibility and an active-point routing decision produce different behavior on real footage.

The three planned rates gave **0.66% fewer return bytes** at equal reconstructed-plate luma PSNR over just **41.768–41.887 dB**. Adding the two predeclared support points gave **0.57% fewer return bytes** over **38.845–45.452 dB**, measured by PCHIP BD-rate against the fresh encode envelope. Restricting PSNR to pixels outside the return erasure rectangles gave **0.64% fewer bytes**. In this transition, holding the nominal CRF fixed changes quality substantially: at 38 the update cost 68,112 bytes at 38.59 dB and the new reference cost 272,861 bytes at 44.69 dB. The equal-quality effect is small.
