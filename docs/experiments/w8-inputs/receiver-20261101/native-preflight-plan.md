# Prospective native library inventory

`experiments/tennis/w8_receiver_native_preflight.py` is prepared for root review; no remote run or GPU work is authorized by this document. It opens the fixed paid packet, verifies the complete packet and IVF section, and uses the pinned MAIN FFmpeg on all 240 coded frames. `-re` paces the input to keep the process alive while the host-local supervisor inspects actual `/proc/<owned-pid>/maps` after decoding begins. The snapshot must include the exact FFmpeg executable, its ELF interpreter, and one `libdav1d.so` under the explicitly permitted MAIN or system library roots. Every mapped regular file is hashed, with a 1 GiB total hash cap. The actual mapped `libdav1d` is loaded by absolute path and its `dav1d_version()` must report 1.5.4. The utility keeps the stdout/stderr, process handles, timeout/failure record and partial YUV on host-local scratch.

A complete 47,001,600-byte raw YUV output must hash to `7490edf9b678db805c23baae49a2a3b5e9d7b037b18dd216320aad47a061beff`, from the locally recovered native manifest SHA256 `8dd22cf9320b0d04809a8f34d0f4961d812f8488909043ef2bbeeba14090c15b` in the original native-base archive SHA256 `ea64cb7029e962df557f05e5c0b457faa0e6475135b722a083b367bc2f9ca464`. This checks original decoded YUV; it does **not** establish RGB conversion or receiver isolation. The inventory decode is not the later isolated receiver decode.

Prospective aggregate ceiling: 6 parent CPU-s, 1 version-command CPU-s, 9 decoder CPU-s and 4 CPU-s for the separate launcher, transport, monitoring and audit, totalling 20 CPU-s inside the remaining W8 budget; 120 s wall, one CPU and GPU hidden. The utility applies the first three individual limits and records child usage; the reviewed outer launcher must enforce and charge its separate 4-s bound and deadline, own the process group, preserve job identifiers, and supply an already-existing host-local `audits` directory. It creates one fresh output subdirectory on `/local/users/emanuele/pointstream`, verifies that filesystem is distinct from the data filesystem and has 200 MB free, and never writes to `Datasets` or `Models`.

The reviewed config is a SHA256-pinned JSON object with exact `packet`, `ffmpeg`, `library_dirs`, `output`, `parent_cpu: 6`, `version_cpu: 1`, `decode_cpu: 9` and `wall_seconds` (1–120). `packet` must be the installed paid packet; `ffmpeg` must resolve beneath the cached MAIN environment and match SHA256 `7556f7249282a43dfaa02b776d4d6ad8b01a8865bfbca790a018a9c5d98103d2`; each library directory must resolve within the cached MAIN tree or permitted system-library roots. Paths, host, loader, library directories and output are not yet asserted available. The future restricted worker's allowlist must come from the reviewed actual mapping and independently verify those file identities again, rather than treating an inventory receipt as an isolated decode. Any failure, timeout, absent dependency, unknown mapping, version mismatch or exhausted bound stops promotion and preserves partial files.
