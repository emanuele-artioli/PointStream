Count separate process parents/children, environment and file hashing, single-thread bootstrap, device qualification, model loads, native decode, conversion, output hashes, disk IO and retention. 4. **Compose and seal (MAIN).** The `compose` worker uses only the paid packet geometry/order, newly generated crops, fresh predicted masks and native RGB base; it writes 80 composites and receipt with exact base fallback. Independently reopen and cross-check actual generation, mask, base and composite files against every seal before any original source or golden is accessible. Budget CPU composition, memory-map reads/writes, per-frame and whole-file hashes, validator and publication. Receiver workers must deny original source, prepared/fit archives, golden outputs and their aliases throughout.
5. **Offline judge only after the candidate seal.** `w8_receiver_score.py --phase source` prepares/qualifies the original RGB under separately reviewed limits; `--phase score` loads pinned source/target masks and LPIPS/DISTS networks and computes player and whole-frame per-tick scores. `w8_receiver_finish.validate_offline` reopens source-bound score and candidate seals, compares the saved qualified golden base/composite and both binary masks, and emits the final validation. Include source decoding, model/asset hashes and loads, GPU scoring, all CPU/GPU time for file IO, metric validation, retained artifacts, archive publication, independent audit, supervision and cleanup. The immutable rule is exact RGB preferred, otherwise every RGB channel differs by at most one level, both binary masks are bit-identical, and each tick **and** mean for all four player/whole LPIPS/DISTS differences is at most 0.001. Missing data or any failed gate stops the witness.
