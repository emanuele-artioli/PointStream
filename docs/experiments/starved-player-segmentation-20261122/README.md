# Can a receiver read player silhouettes more accurately than extracting them from decoded video?

Use the 12 source-reviewed native ticks, 24 body-only masks, and the actual lossless-conditioned clean-base CRF60 composition from the 50-fps Nadal rally. A receiver-derived SAM compositing mask already exists for each player. Compare it with the result of a practical independent YOLO26x instance-segmentation checkpoint on four actual RGB inputs: the source, plain AV1, ROI AV1, and the PointStream composition. Native controls cost 66.105 and 64.853 kbps. The PointStream packet costs 469.335 kbps cold or an ideal 65.473 kbps when the complete reference payload is discounted. The cheaper running price remains a scenario and both actual baseline rates must be shown.

Freeze the model, preprocessing (1280-pixel inference size, person class, confidence 0.25, NMS IoU 0.7 and native-resolution masks), and tick list before opening model outputs. Supply only full RGB frames to the detector; it receives no human masks, source prompts, track boxes or source/candidate IDs. Score one-to-one by maximum total IoU against the source body masks, assign zero to unmatched people and report recall at IoU ≥ 0.5, extra person predictions and per-person IoU. Aggregate by person/tick within this single physical match; report the nine proposal-assisted and three unprompted label frames separately. There are no absent-player frames. Retain extra detections, including people outside the two player labels, without interpreting them as validated false positives. Measure timing on one CPU and report the direct signal as a product of receiver-side rendering/SAM processing. Nominate extra checkpoints or new source-only labels only if they could change the result.

Use one real-tick smoke with all four inputs, then the original twelve ticks only if model/runtime hashes, input masks, output geometry and a conservative timing projection pass. One campus CPU, no GPU, up to 1,600 CPU-seconds for the staged inference plus 120 local CPU-seconds for preparation and scoring. Preserve only numeric predictions/rectangular binary mask regions, timings and manifests. No new deployable codec or population-level claim follows from one development match.
