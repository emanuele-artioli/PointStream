# Can a sender choose a ball representation without the target shot’s quality scores?

The main ball plot selects the best affordable measured stream on each source using its score. This inexpensive follow-up tests the decision a sender could make with pre-encoded streams and byte counts. The 15 and 20.4 kbps seven-match curves and the 35 kbps twelve-match curves have already been seen. This is a retrospective leave-one-match-out check with fixed choices, not a prospective streaming test.

At each ceiling, hold one whole match out. Among ordinary AV1 at widths 320/640, PointStream at widths 320/640, and full tested DCVC-UF, choose the family and preferred width with the lowest mean ball DISTS on the other matches. Break ties by the written order. For each family and width, select the largest affordable native file by paid bytes, with packet hash breaking ties. If a preferred width is unavailable, use the largest affordable file from the same family. Where the measured scene selector routes to ordinary video, substitute ordinary AV1 at the preferred width for a PointStream request. Use the same rule during fitting and evaluation. Neither the target’s region labels nor its quality scores enter its choice. The file sizes and routing decision are assumed available at the server. There is no selection using the target’s pixels beyond that existing routing decision. Real-time encoding cost, buffer state and future throughput remain separate questions.

Compare the realized policy with ordinary AV1 (width chosen on the other matches), always using the neural codec, and the best affordable routed stream selected with the target’s scores. The decision for the paper is whether the observed change near 20 kbps survives removal of target quality from the selector. If the inexpensive rule loses or frequently chooses a different family, report that an oracle curve alone does not supply a switching policy. Freeze these three existing cohorts/prices, preserve every original match and do not tune the heuristic after scoring. Reuse the [physical stream measurements](../cohort-expansion-20261122/three-family-all-verified.md) and [source routing](../official-test-route-20261122/result.json). Allow two local CPU-minutes and zero GPU time.
