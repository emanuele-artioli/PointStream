Its 88.3007-second first point and 18.4783-second second point do not by themselves establish which costs can safely be amortized. The currently specified conservative forecast uses the slower point for all 22 with a 1.5 margin. This is a lower bound for that forecast, not a complete forecast or a full-study admission.

The actual transfer and any launch require an explicit root decision; this card allocates nothing.
