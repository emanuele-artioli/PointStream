# Registered-frame task scorer audit

The task scorer at `3f7c121` compared only `min(reference_records, prediction_records)` and paired records by list position. A missing prediction suffix could remove reference hands from the denominator of a metric named `pck50_all_gt`; record order could change matches even when frame IDs were unchanged. The corrected scorer registers the complete supplied reference frame-ID set, aligns predictions by ID, counts absent predictions and unmatched reference hands, and rejects duplicate or out-of-window IDs. This cannot certify that the supplied reference itself includes every source frame: decoded source identity and complete reference manifests are still required. Association/thresholds are unchanged. Model-derived reference observations remain model-derived.

## Experiment fixed before scoring

The [preregistration](task-denominator-preregistration.md) fixes three retained RTM-reference caches, three prediction paths, sorted suffix removal fractions 25/50/75%, record reversal, and unchanged hand association. Selected JSONs were copied read-only from the existing GPU1 pose-cache directory into external `/private/tmp/task-evidence-inputs`; no model inference, encoding, training, or GPU allocation was used. CPU work was local with OpenBLAS/OpenMP limited to one thread. A first-clip same-entrypoint smoke passed before the three-clip replay.

The complete reference records cover IDs 0–299 on each clip and contain 256, 272 and 263 model-reference hand instances. All nine full-cache comparisons have 300 prediction records, no missing frame IDs, and identical legacy/corrected scores. This evidence **does not show historical suffix truncation in these nine selected cache pairs**. It does not establish original media alignment, independent human truth, or training exposure. The encoder cache is the raw MediaPipe observation path; it is not the separately reported quantized-wire path.

The controlled removal experiment demonstrates the denominator failure on real retained observations. Removing the final 150 prediction records for clip01 leaves 125 reference hands in the legacy denominator versus 256 in the corrected denominator. The candidate-display PCK changes from legacy 0.5189 to corrected 0.2533; the AV1-display PCK changes from 0.5337 to 0.2606. These are deliberately impaired cached observations, not new codec reconstructions. Reversing prediction record order changes legacy clip01 candidate PCK from 0.5097 to 0.3093, while corrected scoring remains 0.5097. Across all nine prediction paths the corrected full denominator remains invariant under removal and order changes; missing-record counts are exactly 75, 150 and 225.

A separate arithmetic audit of 75 saved metric rows reproduces `all_reference_PCK = matched_PCK * matched_hands/reference_hands` within 5.56e-17. None of those 75 rows contains registered/missing-frame counters. This bounds what their aggregates reveal; it is not evidence they actually truncated frames. Source linkage is verified in `eval_split_teleop.py` (control/display rows) and `reconstruct_rtm_encoder.py` (wire/display rows), both importing the audited scorer. Version lineage and source-frame identities remain necessary before attributing this failure to other historical results.

## Truth, source and exposure search

The bounded search inspected the recovered dossier's egocentric/SAM source, adaptation and exposure cards; current curated manifest; shared external data assets/manifests directory inventory through depth two; and Egocentric-10K JSON/CSV/TXT inventory through depth two. The latter yielded curated manifests/candidate lists, no independent hand annotation records in that searched scope. The curated manifest names factory035 for clip01 while the selected historical cache/report identity names factory001. This mismatch remains unresolved; filenames alone do not certify a source pairing. This is a bounded negative search, not proof that annotations do not exist elsewhere. The initially sandboxed six-host inspection failed DNS; the authorized network inspection succeeded for GPU1/GPU3/GPU5, timed out for GPU2/GPU6 and reported GPU4 locked. No GPU was chosen or claimed.

Held-out exposure is unqualified: the documented overfit training path has no independent validation partition and lacks exact evaluation/training frame hashes and model digests. A source checkpoint and fresh-package candidate plus conventional baseline, matched model access, charged adapted weights/appearance, decoded source-frame identity and independent all-frame labels remain required for task-accuracy/compression claims. The controlled experiment supports an instrument correction and a missingness-reporting requirement, not an algorithmic negative or advantage.
