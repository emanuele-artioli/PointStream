# Racket source feasibility

`racket-detection.pdf` summarizes the fixed source and three existing decoder paths from `docs/experiments/racket-source-oracle-20261122/`. Counts are one-to-one official box matches at IoU ≥0.5 on 15 labeled frames, not trajectory, silhouette, grip or full-video recall. One fixed COCO detector and threshold are used throughout; pretraining overlap is unknown. The source-gate pass motivates a separately billed full-cadence racket-tile pilot; the AV1-plus-ball-tile row does not include a racket stream. Rates are actual complete ball-study stream rates; Washington ROI is materially lower than the others.

`racket-crop-oracle.pdf` is a supplementary exploratory feasibility result on match209, not a paid codec point. The detector ran on all 64 source ticks and selected 70 exact source rectangles, but only six boxes on five ticks have official labels. Perfect source-pixel pastes onto the 61.353 kbps ordinary base recovered 3/6 at the predeclared IoU 0.5, below the 4/6 gate, and 5/6 at diagnostic IoU 0.3. Source and reconstructed frames use the same detector; no crop bitrate, temporal correctness, false-positive rate or grip quality was established. See `docs/experiments/racket-crop-gate-20261122/` for the fixed rule and all predictions.
